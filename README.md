# 刘耘彤 · 作品集

纯静态网页，无需安装依赖或构建。

## GitHub Pages 部署

1. 解压 ZIP，把里面的所有文件与文件夹上传到 GitHub 仓库根目录，确保 index.html 位于根目录。
2. 打开仓库 Settings → Pages。
3. Source 选择 Deploy from a branch，Branch 选择 main，目录选择 / (root)，保存。
4. 等待部署完成，打开 Pages 显示的网址。

如果已有网站，请先备份；此包是当前金色粒子树版本。

## 本地预览

在本目录运行 python -m http.server 8000，然后访问 http://localhost:8000。

## 操作

滚轮 / 上下方向键切换；首页光点进入公司，概览光簇或左侧列表进入项目。
